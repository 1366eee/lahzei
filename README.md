# لحظه‌ای — قیمت طلا، ارز، رمزارز و آب‌وهوای ایران 🇮🇷

اپلیکیشن اندروید برای نمایش **قیمت لحظه‌ای طلا (۱۸ و ۲۴ عیار، سکه و…)، دلار بازار آزاد، ارزهای دیجیتال، ارزهای جهانی** و **آب‌وهوای بیش از ۱۶۰ شهر ایران** به‌همراه **مبدل همه‌کاره به تومان**.

> کل کد فقط Kotlin + XML است، بدون هیچ سرویس پولی یا کلید API. بیلد نهایی به‌صورت **خودکار در GitHub Actions** انجام می‌شود و APK آماده نصب را می‌گیرید.

## 🚀 گرفتن APK در ۵ قدم (بدون نصب هیچ چیزی روی کامپیوتر)

### قدم ۱ — ساخت ریپازیتوری
1. وارد [github.com/new](https://github.com/new) شوید.
2. یک نام انتخاب کنید (مثلاً `lahzei`) و **Public** بگذارید.
3. روی **Create repository** بزنید.

### قدم ۲ — آپلود فایل‌ها
1. در صفحه ریپو روی **uploading an existing file** کلیک کنید.
2. **محتویات داخل پوشه‌ی پروژه** (نه خود پوشه!) را با درگ‌اند‌دراپ بیندازید؛ یعنی همه چیز باید مستقیم داخل ریشه ریپو باشد:
   ```
   lahzei/
   ├── .github/workflows/android.yml   ← خیلی مهم
   ├── app/
   ├── gradle/
   ├── build.gradle
   ├── settings.gradle
   └── ...
   ```
3. روی **Commit changes** بزنید.

> ⚠️ اگر `.github` را آپلود نکنید، بیلد خودکار انجام نمی‌شود. مرورگر اجازه آپلود پوشه مخفی را می‌دهد؛ اگر نداد، از داخل پوشه `.github/workflows` فایل `android.yml` را دستی آپلود کنید.

### قدم ۳ — اجرای بیلد
1. به تب **Actions** بروید.
2. اگر پیام «Workflows aren't being run on this repository» دیدید، دکمه سبز **I understand my workflows, go ahead and enable them** را بزنید.
3. بیلد **Build Android APK** باید شروع شده باشد (به‌صورت خودکار با اولین push اجرا می‌شود).
4. حدود ۴ تا ۸ دقیقه صبر کنید تا تیک سبز ✅ بیاید.

### قدم ۴ — دانلود APK
1. داخل همان اجرای بیلد، پایین صفحه بخش **Artifacts** را ببینید.
2. **Lahzei-release-APK** را دانلود کنید (پیشنهادی — امضاشده و قابل نصب) یا **Lahzei-debug-APK**.
3. فایل ZIP دانلودی را باز کنید؛ داخلش `app-release.apk` است.

### قدم ۵ — نصب روی گوشی
1. فایل APK را به گوشی بفرستید (تلگرام/کابل/درایو).
2. هنگام نصب، اجازه **Install unknown apps** را بدهید.
3. تمام! اپ «لحظه‌ای» نصب شد. 🎉

## 🏷 نسخه‌بندی (اختیاری ولی توصیه‌شده)

اگر بخواهید APK همیشه در بخش **Releases** باشد:

```bash
git tag v1.0.0
git push origin v1.0.0
```

یا در وب: تب **Releases → Draft a new release → Choose a tag** تایپ کنید `v1.0.0` و Publish بزنید.

با هر تگی که با `v` شروع شود، ورک‌فلوی ساخته‌شده **به‌صورت خودکار APK را به Release ضمیمه می‌کند** و همه می‌توانند از صفحه Releases دانلودش کنند.

## 💻 روش دوم: با خط فرمان

```bash
git clone https://github.com/USERNAME/lahzei.git
cd lahzei
# فایل‌ها را اینجا کپی کنید
git add .
git commit -m "Lahzei v1.0.0"
git push origin main
```

بیلد لوکال (اختیاری — Android Studio هم کافی است):

```bash
./gradlew assembleDebug     # خروجی: app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease   # خروجی: app/build/outputs/apk/release/app-release.apk
```

## 🛠 شخصی‌سازی

| چه می‌خواهید؟ | کجا؟ |
|---|---|
| افزودن شهر جدید | `app/src/main/java/com/lahzei/app/data/Cities.kt` |
| افزودن ارز جدید به لیست | `ui/currency/CurrencyFragment.kt` → `CurrencyList` |
| تغییر تعداد رمزارزها | `data/Data.kt` → پارامتر `per_page` |
| تغییر نام و آیکون اپ | `res/values/strings.xml` و پوشه `mipmap` |
| تغییر رنگ‌ها | `res/values/colors.xml` و `values-night/colors.xml` |

بعد از هر تغییر، push کنید — گیت‌هاب خودش APK جدید می‌سازد.
